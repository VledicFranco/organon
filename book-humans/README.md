# Organon Book for Humans

**Status:** 🚧 Planned — Coming Soon

## What Will Be Here

A narrative-focused introduction to the Organon Methodology for **human readers** — complementing the technical reference in [../book-llms/](../book-llms/).

### Planned Content

**Chapter 1: The Documentation Drift Problem**
- Why traditional documentation fails (manual updates, drift, staleness)
- The cost of outdated architecture docs
- Real-world examples of documentation disasters

**Chapter 2: The Organon Solution**
- Code as single source of truth
- Auto-generation prevents drift
- Dual mapping for flexible navigation
- Verification gates ensure freshness

**Chapter 3: Getting Started**
- Installing organon-tools
- Your first domain organon
- Understanding ETHOS.md, PHILOSOPHY.md, PROTOCOLS.md
- Running verification gates

**Chapter 4: Advanced Patterns**
- Feature detection conventions
- Cross-domain discovery
- RFC-driven implementation workflow
- Methodology organons (meta-level)

**Chapter 5: Case Study — Agent Tavern**
- How Agent Tavern uses Organon
- Lessons learned
- Migration from manual docs
- Scaling to 10+ domains

**Appendices**
- Template library
- Common anti-patterns
- Migration guide from traditional docs
- FAQs

## Differences from book-llms/

| Aspect | book-llms/ | book-humans/ |
|--------|-----------|-------------|
| **Format** | Technical reference | Narrative guide |
| **Structure** | Invariants → Patterns → Templates | Problem → Solution → Tutorial |
| **Examples** | Code-heavy | Story-driven |
| **Tone** | Prescriptive | Explanatory |
| **Audience** | LLMs + advanced devs | All developers |
