## About These Docs

These docs target **human developers** who want practical guidance. They complement — but do not replace — the formal methodology in `book-llms/`.

| Resource | Purpose | Audience |
|----------|---------|----------|
| `docs/` | How to use Organon (practical, hands-on) | Developers |
| `book-llms/` | Formal methodology spec (invariants, patterns, templates) | LLMs + advanced developers |
| `book-humans/` | Why Organon works (philosophical narrative) | All developers |
| `README.md` | First impression / landing page | Everyone |
